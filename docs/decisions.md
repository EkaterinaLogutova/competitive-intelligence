# Решения по проекту

## Границы результата

- Каждое из трех заданий готовится как отдельный файл в `submission`.
- Сырой контент сайтов не коммитится: он может быть объемным, меняться и содержать
  персональные данные или материалы с ограничениями на распространение.
- Реестр `config/sources.json` хранит только выданные URL и предварительные гипотезы о
  типе источника. Гипотезы не считаются итоговой классификацией.
- Нормализованная запись отделена от сырого ответа, чтобы результат можно было повторно
  обработать после изменения правил без нового запроса к сайту.

## Исследовательские решения

- Тип площадки, страницы и материала размечаются раздельно.
- Пустая коллекция считается корректным наблюдением, а не ошибкой.
- Поля автора и издателя не объединяются.
- Относительная дата хранится вместе с нормализованным временем и признаком
  приблизительности.
- Обучающая и проверочная выборки будут разделяться по доменам.
- На шести URL модель не обучается: сначала расширяется и независимо размечается корпус.
- Правила служат первой точкой отсчета; усложнение модели оценивается одновременно по качеству
  и времени обработки.
- Генерация сводок сравнивается с простым выбором предложений из исходных текстов и
  проверяется только на документах
  со ссылками на исходные материалы.
